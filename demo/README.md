# Interactive Demo

Open `index.html` in any modern browser (no build step).

It provides fully interactive mock data for:

- **Overview** — live agent table with CPU / Memory / GPU-NPU / tokens
- **Trace** — waterfall of a multi-step agent run + resource overlay
- **Snapshot** — point-in-time process/pod view with inspect

The full `index.html` lives in this directory in the source tree. If it is not present in the GitHub tree yet, clone the repo and copy from your local `artifacts/resonance/demo/` or request the latest push.

Brand colors used: warm charcoal `#0e0f0c`, cream `#f0ece3`, sage accent `#8a9e90`.
